# Vertex AI to OpenAI Proxy

A production-grade proxy that translates OpenAI-compatible API requests into Google Vertex AI (Gemini) API requests, allowing coding agents (OpenCode, Cline, Cursor, Roo Code, Kilo Code, etc.) to seamlessly utilize Google Cloud's Vertex AI models.

---

## 🚀 One-Click Quick Deployment (Google Cloud Console / Cloud Shell)

Deploy directly to **Google Cloud Run** using the automated deployment script.

### Steps:

1. Open **Google Cloud Shell** in your Google Cloud Console.
2. Clone this repository and navigate into the directory:
   ```bash
   git clone <your-repo-url>
   cd vertex-openai-proxy
   ```
3. Run the automated deployment script:
   ```bash
   ./deploy.sh
   ```

### What `deploy.sh` automatically does for you:
- Enables all necessary GCP APIs (`aiplatform`, `run`, `firestore`, `iam`, `cloudbuild`, `artifactregistry`).
- Provisions a Firestore database in Native mode.
- Creates an **Admin Service Account** (`vertex-admin-sa`) with full Vertex AI & Firestore permissions.
- Generates and saves `key.json` in the project root.
- Builds and deploys the container to **Google Cloud Run**.
- Outputs your live Cloud Run URL, Admin Credentials, and OpenAI-compatible endpoint.

---

## 🤖 Using with OpenCode / Coding Agents

Once deployed, copy your **Cloud Run Base URL** (e.g. `https://vertex-openai-proxy-xyz-uc.a.run.app`).

### Configuration for Coding Agents:
- **Base URL**: `https://<YOUR-CLOUD-RUN-URL>/v1`
- **Model**: `gemini-2.5-pro` (or `gemini-1.5-pro`, `gemini-2.0-flash`)
- **API Key**: Login to the Web Admin UI at `https://<YOUR-CLOUD-RUN-URL>` using the admin email and password generated by `deploy.sh` to generate an API key.

## 💻 Local Development

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Ensure `key.json` exists in project root.
3. Install dependencies and start:
   ```bash
   npm install
   npm run dev
   ```
